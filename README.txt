PROYECTO: PYTHON Y REDES

Tema: Bibliotecas de Python para comunicaciones de red.

Este proyecto presenta y demuestra el uso de distintas
bibliotecas de Python aplicadas a las redes informáticas.

Bibliotecas estudiadas:
- Requests
- Aiohttp
- Socket
- WebSockets

CONTENIDO:

01_Codigo:
Contiene los programas desarrollados y probados.

02_Presentacion:
Contiene las diapositivas para la exposición.

03_Documentacion:
Contiene el informe en formato PDF.

INSTALACION:

Para instalar las bibliotecas necesarias,
ejecutar en la terminal:

python -m pip install -r requirements.txt

NOTA:
La biblioteca socket ya viene incluida en Python.
